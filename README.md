# 🌿 EcoFlow — адаптивный лендинг экосервиса

EcoFlow — демонстрационный проект современного адаптивного лендинга для технологичного экосервиса.

Сайт представляет концепцию цифрового сервиса, который помогает пользователям рационально расходовать ресурсы, управлять энергопотреблением и экономить.

Проект разработан с использованием HTML, CSS и JavaScript без сторонних UI-фреймворков.

## 🚀 Демо

**[Посмотреть сайт](https://germakov.github.io/ecoflow-landing/)**

## ✨ Возможности

- 📱 Адаптивный дизайн для компьютеров, планшетов и смартфонов.
- 🌙 Переключение светлой и тёмной темы.
- ☰ Мобильное меню с открытием и закрытием.
- 🧮 Интерактивный калькулятор экономии.
- 💳 Карточки тарифных планов с возможностью выбора.
- 📝 Демонстрационная форма обратной связи.

- ♿ Базовые элементы доступности: ARIA-атрибуты и семантическая HTML-разметка.

## 💻 Локальный запуск

Для просмотра проекта не требуется установка дополнительных зависимостей.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/germakov/ecoflow-landing.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd ecoflow-landing
   ```

3. Откройте файл `index.html` в браузере.

Для разработки также можно использовать локальный сервер, например Live Server в VS Code.

## 📱 Адаптивность

Лендинг адаптирован под различные размеры экранов.

В процессе разработки проверялось отображение при ширине:

- 320 px — небольшие смартфоны.
- 375 px — смартфоны.
- 768 px — планшеты.
- Десктопные разрешения.

Для мобильных устройств реализовано раскрывающееся навигационное меню.

## ⚙️ Интерактивные элементы

### Калькулятор экономии

Пользователь может изменять параметры калькулятора и получать расчёт предполагаемой экономии.

Расчёты являются демонстрационными и не представляют собой гарантированный прогноз.

### Выбор тарифного плана

При выборе тарифа сайт:

1. Определяет выбранный план.
2. Прокручивает страницу к форме обратной связи.
3. Отображает название выбранного тарифа.
4. Сохраняет выбор в скрытом поле формы.

### Переключение темы

Пользователь может переключаться между светлой и тёмной цветовой схемой сайта.

## ⚠️ Ограничения демонстрационной версии

**EcoFlow — учебный демонстрационный проект, а не действующий коммерческий сервис.**

Форма обратной связи не подключена к серверу и не отправляет заявки.

Тарифы, расчёты экономии и описание сервиса используются для демонстрации интерфейса.

Для коммерческого использования потребуется подключить серверную обработку заявок или интеграцию с CRM, электронной почтой либо Telegram-ботом.
